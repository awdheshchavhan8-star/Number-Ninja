# Number-Ninja 🥷

A simple, interactive number guessing game built using Python. 

## 🚀 Features
* Generates a random number for the user to guess.
* Tracks the number of attempts.
* Provides interactive "too high" or "too low" feedback.

## 📦 Prerequisites
Make sure you have Python installed on your system. You can download it from [python.org](https://python.org).

## 🎮 How to Run the Game
1. Clone this repository or download the files.
2. Open your terminal or command prompt in the project folder.
3. Run the following command:
   ```bash
   python "Number Ninja.py"
   ```

## 🛠️ How to Play
* The computer will pick a random secret number between 1 to 100.
* Input your guess when prompted.
* Follow the hints until you guess the correct number!
